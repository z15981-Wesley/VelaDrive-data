Copies of Taiwan open data whose portals refuse connections from outside Taiwan (so the weekly
GitHub job can't download them). Downloaded in Taiwan; 政府資料開放授權條款－第1版.

- chiayi_county.csv — 嘉義縣警察局固定式測速照相設置地點 (data.gov.tw 178143)
- hsinchu_county_zone.csv — 新竹縣政府警察局區間平均速率裝置 (data.gov.tw 172950)
- kaohsiung_zone.csv — 高雄市科技執法區間平均速率執法設備設置地點 (data.gov.tw 151949)
